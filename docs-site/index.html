From account to insight: the complete data‑collection workflow

A step-by-step walkthrough for enumerators and project owners — from creating an account to submitting a questionnaire and reading the results, using the EAC User Satisfaction Survey as a live example.

Before the session

Have these ready and each participant will move through every step without waiting on anyone else.

  • A personal email address you can access during training
  • The project's questionnaire, saved as an .xlsx file
  • A laptop or tablet with a browser (Chrome or Safari recommended)
  • Access to loyalminds.org
01

Create an account

Every enumerator and project owner needs their own account — never share a login. Go to loyalminds.org/accounts/signup and complete the registration form.

  1. Enter your Full name, choose a Username, and enter a real Email — you'll need it in the next step.
  2. Select your Country, Organization type, and Organization name.
  3. Choose a Password and repeat it, then select Create Account.
02

Verify your email

LoyalMinds sends an activation link the moment you register. The account stays inactive until you click it — this confirms the email address is really yours.

Can't find the email? Check the spam or junk folder first. The link is valid for a limited time — if it has expired, request a new one from the login page.
03

Log in

Once your account is active, sign in with your username and password at loyalminds.org/accounts/login.

04

Forgot your password?

From the login screen, select Forgot password? Enter the email address on your account and a reset link will be sent.

Building the project
05

Create a new project

A project can start from a blank form, a template, or an existing XLSForm spreadsheet. This guide uses the third option — the fastest way to bring a questionnaire designed in Excel onto LoyalMinds.

  1. From the dashboard, select the blue NEW button.
  2. Choose Upload an XLSForm from the source menu.
  3. Select the file, or drag and drop it into the upload area.
  4. Review the project name and details LoyalMinds detected from the file, then select Create project.
06

Deploy the project

A project must be deployed before it can collect real data — deploying publishes the current version of the form and generates the link enumerators will use in the field.

  1. Open the project and select deploy from the summary panel.
  2. Confirm — the status changes from Draft to Deployed, and a Collect data panel appears with the form's web link.
Every change needs a redeploy. Editing the form after this point only updates the draft — select redeploy to publish your changes to the live form.
Collecting data
07

Fill in the form

Selecting Open next to the web-form link launches the questionnaire exactly as a respondent or enumerator will see it — consent statement first, then each section in order.

Required questions are marked with *. A question left blank when required will be highlighted in red when you try to move on.
08

Save as draft — working offline

LoyalMinds forms are built to work with no connection at all. Answers are written to the device's own storage as you go, so an interview is never lost to a dead battery or a dropped signal.

  1. Select Save Draft at any point to pause an interview and continue later — give the draft a name you'll recognize.
  2. The record is now held in the browser's local queue, shown by the counter in the top-left corner.
  3. Reopen the queue at any time to resume, export, or force an upload.
How offline mode really works: completed (non-draft) records upload automatically every five minutes once the page is open and a connection returns. Drafts wait for you to reopen and finish them on purpose — select Upload in the queue to force a submission attempt immediately.
09

Submit the completed form

Once every required question is answered, select Submit. LoyalMinds validates the responses, and — if a connection is available — sends the record straight to the project.

After collection
10

View submitted data and reports

Back in the project, open the Data tab to see every submission as it arrives.

  1. Table lists every submission as a row, with each question as a column.
  2. Reports turns the same data into automatic charts and frequency tables — one per question — updated as new submissions come in.
The banner on every automated report is a genuine reminder, not boilerplate: treat these charts as a first look, and clean the data before using figures in an official publication.
11

Download the data to your computer

From Data → Downloads, export the full dataset as a file you can open in Excel, SPSS, or Stata.

  1. Choose an export type — XLS is the most portable choice for most teams.
  2. Choose the Value and header format — typically the language your team reads.
  3. Select Export. LoyalMinds prepares the file and lists it under Exports below.
  4. Select Download next to the finished export, and save it to your computer like any other file.
Exports don't update on their own. If new submissions arrive after you generate one, run Export again to include them — each export is a snapshot at the moment you created it.
